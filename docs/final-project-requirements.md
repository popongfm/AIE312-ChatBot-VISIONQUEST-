# Final project Requirement Announce

สวัสดีครับนักศึกษาทุกคน

โปรเจกต์ปลายภาคของเราคือ **"Chat AI พร้อม Portfolio ของกลุ่ม"** ทำเป็นกลุ่มละ **3-4 คน** คือเว็บแอปที่ให้ผู้เยี่ยมชมพูดคุยกับ AI เพื่อสอบถามเรื่องราว ผลงาน และทักษะของกลุ่มและสมาชิกแต่ละคน

## สิ่งที่ต้องมีในโปรเจกต์

1. **หน้าเว็บ Portfolio ของกลุ่ม** ประกอบด้วย
   - แนะนำกลุ่ม: ชื่อกลุ่ม แนวคิด/จุดเด่นของทีม และผลงานที่ทำร่วมกัน
   - แนะนำสมาชิกรายบุคคล: ชื่อ บทบาทในทีม ทักษะ และผลงานหรือโปรเจกต์ของแต่ละคน
   - ช่องทางติดต่อของกลุ่ม
2. **Chat UI** (React): หน้าแชตที่ใช้งานได้จริง แสดงข้อความของผู้ใช้และ AI แยกชัดเจน
3. **Backend API** (Express): รับข้อความจาก Chat UI แล้วส่งต่อไปยัง AI
4. **ฐานข้อมูล PostgreSQL**: เก็บประวัติการสนทนาอย่างน้อย และข้อมูล Portfolio ของกลุ่มและสมาชิกถ้าต้องการ
5. **การเชื่อมต่อ AI**: AI ต้องตอบคำถามโดยอิงข้อมูล Portfolio ของกลุ่มและสมาชิกทุกคน ไม่ใช่ตอบทั่วไป (เช่น กำหนด system prompt หรือส่งข้อมูล Portfolio เป็น context) และต้องตอบได้ทั้งคำถามเกี่ยวกับกลุ่มโดยรวมและเกี่ยวกับสมาชิกแต่ละคน
6. **CI/CD**: มี pipeline สำหรับ build/deploy โปรเจกต์โดยอัตโนมัติ
7. สามารถแต่งเติมความคิดสร้างสรรค์ลงผลงานได้เต็มที่ (ในหน้าเว็บทั้ง 2 หน้า)

## สิ่งที่ต้องส่ง

- ลิงก์ GitHub repository พร้อม `README.md` อธิบายวิธีติดตั้งและรันโปรเจกต์
- ไฟล์ `.env.example` (ไม่ใส่ key จริง)
- ลิงก์เว็บที่ deploy แล้ว
- ไฟล์ Presentation
